Student Event Registration Formatter

A Python program that cleans student registration inputs and formats the event date clearly.

What It Does
- Formats student name and event title using `.strip()` and `.title()`
- Converts name code and section to uppercase using `.upper()`
- Formats the event date using Python's `datetime` library

 Versions
- Version 1: Basic input and output
- Version 2: Added string formatting
- Version 3: Added date formatting
